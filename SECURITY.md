# Security Policy

## Supported versions

Only the latest release receives security fixes. The app updates itself; please make sure you are on the newest version before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through [GitHub Security Advisories](https://github.com/woodchen-ink/czlbrowser/security/advisories/new), or email **support@czl.net**. Include the affected version, steps to reproduce and the impact you expect.

We aim to acknowledge reports within 3 working days and will keep you updated until a fix is released.

---

## 安全问题反馈

请不要公开提交 Issue。通过 [GitHub Security Advisories](https://github.com/woodchen-ink/czlbrowser/security/advisories/new) 私下报告，或发送邮件至 **support@czl.net**，并附上受影响的版本、复现步骤和可能的影响。我们会在 3 个工作日内回复。
