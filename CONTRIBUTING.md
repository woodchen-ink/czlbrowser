# Contributing to CZL Browser

**English** | 中文说明见下方

Thanks for helping improve CZL Browser.

## Reporting bugs

Open an issue with the **Bug report** template and include:

- App version (Settings → General) and Windows version
- Kernel type and version (Chrome or Clearcote)
- Steps to reproduce, what you expected and what happened
- Screenshots or the relevant lines from Settings → Logs

Remove account names, proxy credentials and IP addresses before posting.

## Suggesting features

Open an issue with the **Feature request** template. Describe the use case first, then the behavior you want.

## Pull requests

1. For anything larger than a small fix, open an issue first so we can agree on the approach.
2. Branch from `main` and keep each pull request focused on one change.
3. Run the checks below before pushing.
4. Describe what changed and how you tested it.

### Development setup

See [Build from Source](README.md#build-from-source). In short: Go 1.26+, Node.js 20+, Wails CLI v2, then `pwsh scripts/dev.ps1`.

### Checks

```powershell
cd desktop; go vet ./...; go test ./...
cd frontend; npm run build
```

### Conventions

- UI text, log messages and code comments are written in Chinese.
- Frontend: React + TypeScript, Tailwind with the theme's CSS variables (no hard-coded colors), Lucide icons only.
- Backend: methods exposed to the frontend live on `App` in `desktop/`, prefixed `BrowserProfile*`, `BrowserProxy*`, `BrowserCore*`. Data access goes through the DAOs in `desktop/internal/browser/`.
- Don't edit `desktop/frontend/src/wailsjs/` by hand; it is generated by Wails.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/), e.g. `fix(proxy): 修复带密码 SOCKS5 地址的解析`.

## 参与贡献（中文）

- **报告问题**：使用 Bug 模板，附上应用版本、Windows 版本、内核类型与版本、复现步骤和截图或日志（设置 → 运行日志）。发帖前请去掉账号、代理密码和 IP。
- **功能建议**：使用功能建议模板，先说明使用场景，再说期望的行为。
- **提交 PR**：较大的改动先开 Issue 对齐方案；从 `main` 拉分支，一个 PR 只做一件事；推送前跑通上面的检查命令，并说明改了什么、怎么测的。
- **约定**：界面文案、日志和注释使用中文；提交信息遵循 Conventional Commits；不要手动修改 `desktop/frontend/src/wailsjs/`。
